# Hiragana Drill

A simple interactive web application that helps users practice and memorize Japanese Hiragana characters.

## How It Works

- A random Hiragana character is shown on screen
- The user types the correct romaji (which stands for English pronunciation) into the input field
- The app gives instant feedback: ✅ Correct or ❌ Wrong (with the correct answer shown)
- A scoreboard tracks correct answers, wrong answers, and the total count
- A **Skip** button lets the user move to the next character

## Features

- 46 Hiragana characters included (full basic set)
- Random card shuffling on every question
- Real-time score tracking
- Skip functionality
- Clean, simple interface

## Technologies Used

- HTML
- CSS (Vanilla)
- JavaScript (Vanilla)

## How to Run

Open `index.html` in any web browser. No installation or server needed.
